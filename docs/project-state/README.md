# Conexa — Registro de Estado Técnico

Esta carpeta conserva el contexto operativo y técnico de Conexa entre sesiones.

## Archivos
- `CURRENT_STATE.md`: fotografía actual del proyecto y punto de partida.
- `AUDIT_LOG.md`: hallazgos de auditorías.
- `DECISIONS.md`: decisiones técnicas y su motivo.
- `ROADMAP.md`: trabajo pendiente priorizado.
- `CHANGELOG_WORK.md`: registro cronológico de avances.

## Regla de trabajo
Después de cada auditoría o bloque importante de implementación, actualizar los archivos afectados. No marcar una tarea como terminada sin indicar evidencia o verificación.

La próxima sesión debe comenzar leyendo esta carpeta antes de continuar.
